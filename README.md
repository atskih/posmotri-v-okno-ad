# Посмотри в окно

Учебный проект Яндекс Практикума: страница для просмотра коротких видео из разных городов. Можно выбрать город и время суток, переключать видео по карточкам и загружать дополнительные результаты кнопкой «Показать еще».

Репозиторий: [atskih/posmotri-v-okno-ad](https://github.com/atskih/posmotri-v-okno-ad).

## Выполненная работа

- Добавлена вёрстка по макету с помощью Flexbox.
- Оформлены видеоплеер, прокручиваемый список карточек и форма поиска.
- Созданы собственные чекбоксы с помощью псевдоэлементов.
- Добавлены состояния наведения, нажатия, выбора и фокуса с клавиатуры.
- Настроены обрезка длинных заголовков и описаний, размеры изображений и видео.
- Прелоадеры и сообщения об ошибках ограничены соответствующими контейнерами.
- Учтены настройки уменьшения движения и повышенной контрастности.

Исходная HTML-разметка, JavaScript, шрифты и стили компонентов загрузки и ошибок сохранены. Основная работа выполнена в `styles/style.css`.

## Технологии

HTML5, CSS3, Flexbox, БЭМ, JavaScript, внешний API. Шрифты Oswald и Fira Sans Condensed подключены локально в форматах WOFF2 и WOFF.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

При наличии Python можно запустить локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

После запуска откройте [http://localhost:8000](http://localhost:8000).

Для получения видео требуется интернет и доступность учебного API `https://v-content.practicum-team.ru`. При ошибке сервиса приложение показывает сообщение об ошибке.

По условиям задания страница имеет фиксированную ширину 1200 px. Мобильная адаптация в эту проектную работу не входит.

## Структура

- `index.html` — страница и шаблоны карточек, кнопки, загрузки и ошибки.
- `styles/style.css` — оформление страницы и интерактивных состояний.
- `styles/preloader.css` — исходная анимация загрузки.
- `styles/error.css` — исходное оформление сообщения об ошибке.
- `scripts/script.js` — исходная логика поиска, загрузки и выбора видео.
- `fonts/` — локальные файлы шрифтов и их подключение.
- `DESIGN.md` — принятые параметры оформления.
